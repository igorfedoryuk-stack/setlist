# Сетлист гурту

Сайт гурту: сетлист з картками пісень (структура, акорди, текст, PDF, коментарі, готовність, тренування, репетиція, вокалісти), розділ навчання зі шпаргалкою, тренажер грифа (ноти, інтервали, акорди), пресети Boss ME-90 і довідка з підключень.

## Як влаштовано

| Файл | Що це |
| --- | --- |
| `index.html` | Уся сторінка: розмітка, стилі й логіка. |
| `backend.js` | Зв'язок із Supabase: вхід через Google, читання й запис даних, файли. |
| `config.js` | Адреса проєкту Supabase і публічний ключ. |
| `cheat/` | Шпаргалка музиканта (PNG і PDF). |
| `supabase/setup.sql` | Скрипт для Supabase: таблиці, функції з перевіркою доступу, сховище PDF. |

Хостинг — GitHub Pages з гілки `main`. Будь-який коміт у `main` оновлює сайт приблизно за хвилину.

## Вхід і доступ

- Вхід — через Google. Пускає лише тих, чия пошта є в таблиці `members` у Supabase.
- **Додати учасника:** Supabase → Table Editor → `members` → Insert row: `email` (малими літерами, Google-пошта) і `name` (ім'я, яким підписуються коментарі).
- **Забрати доступ:** видалити рядок із `members`.
- Пошти учасників зберігаються лише в базі, не в цьому репозиторії.

## Дані й захист

- Усі записи лежать у таблиці `docs` (колекція, ідентифікатор, JSON). Колекції: `songs` (поле `status`: current, project, vote, archive, solo — лише в особистому списку автора; `gig` — у виступі), `presets`, `mine` (особисте тренування: власна готовність і історія, документ на користувача й пісню), `votes` (голоси За/Проти/Утримуюсь, документ на користувача й пісню), `sections` (плитки налаштувань), `meta` (дані виступу), `comments`, `lessons`, `library`.
- Напряму таблиці недоступні. Сайт читає й пише лише через функції `api_*`, які перевіряють, що пошта користувача є в `members`.
- PDF лежать у сховищі `files` з випадковими назвами; завантажувати й видаляти їх можуть лише учасники.
- Ключ у `config.js` публічний за задумом Supabase; захищає дані вхід через Google і список `members`.

## Типові дії

- **Резервна копія:** на сайті «Налаштування → Дані сайту → Зберегти резервну копію».
- **Перенести дані з файлу:** «Налаштування → Дані сайту → Завантажити дані з файлу».
- **Оновити базу після змін у `setup.sql`:** запустити скрипт ще раз у Supabase → SQL Editor. Дані й учасники не зникнуть.
