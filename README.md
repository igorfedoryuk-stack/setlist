# Сетлист гурту

Сайт гурту: сетлист з картками пісень (структура, акорди, текст, PDF, коментарі, готовність, тренування, репетиція, вокалісти), розділ навчання зі шпаргалкою, тренажер грифа (ноти, інтервали, акорди), пресети Boss ME-90 і довідка з підключень.

## Як влаштовано

| Файл | Що це |
| --- | --- |
| `index.html` | Уся сторінка: розмітка, стилі й логіка. |
| `backend.js` | Зв'язок із Supabase: читання й запис даних, файли, вхід за паролем гурту. |
| `config.js` | Адреса проєкту Supabase і публічний ключ, список учасників для вибору імені. |
| `cheat/` | Шпаргалка музиканта (PNG і PDF). |
| `supabase/setup.sql` | Скрипт для Supabase: таблиця даних, функції з перевіркою пароля, сховище PDF. |

Хостинг — GitHub Pages з гілки `main`. Будь-який коміт у `main` оновлює сайт приблизно за хвилину.

## Дані й захист

- Усі записи лежать у таблиці `docs` (колекція, ідентифікатор, JSON). Колекції: `songs`, `presets`, `lessons`, `comments`, `library`.
- Напряму таблиця недоступна. Сайт читає й пише лише через функції `api_*`, які перевіряють пароль гурту.
- PDF лежать у сховищі `files` у папці, назва якої виводиться з пароля. Без пароля завантажити чи видалити файл не можна.
- Ключ у `config.js` публічний за задумом Supabase; захищає дані саме пароль гурту.

## Типові дії

- **Змінити пароль гурту:** у Supabase → SQL Editor запусти `supabase/setup.sql` ще раз із новим паролем. Учасникам треба буде ввести новий пароль. PDF, завантажені до зміни, лишаться за старими посиланнями, але нові піддуть у нову папку.
- **Резервна копія:** на сайті «Налаштування → Дані сайту → Зберегти резервну копію».
- **Додати учасника до списку імен:** `members` у `config.js`.
